
# GameZone Rental PlayStation

## 1. Nama Proyek

GameZone Rental PlayStation merupakan aplikasi berbasis Java Console yang dibuat untuk memenuhi tugas Latihan Praktikum Pemrograman Java Dasar, Program Studi Pendidikan Teknologi Informasi, Universitas Muhammadiyah Tasikmalaya.

## 2. Deskripsi Singkat

GameZone Rental PlayStation adalah program sederhana untuk membantu petugas rental menghitung biaya penyewaan konsol PlayStation 4 (PS4) dan PlayStation 5 (PS5). Program menerima input nama pelanggan, pilihan konsol, lama bermain, serta pilihan tambahan minuman.

Program secara otomatis menghitung biaya sewa, memberikan diskon sebesar 10% untuk penyewaan minimal 3 jam, menghitung biaya tambahan minuman, dan menampilkan struk pembayaran pelanggan. Program juga menyediakan pilihan untuk melakukan transaksi baru atau mengakhiri program.

## 3. Fitur Program

1. Memasukkan nama pelanggan.
2. Memilih konsol PS4 dengan tarif Rp8.000 per jam atau PS5 dengan tarif Rp12.000 per jam.
3. Memasukkan lama bermain dalam satuan jam.
4. Mendapatkan diskon 10% apabila durasi penyewaan minimal 3 jam.
5. Memilih tambahan minuman seharga Rp5.000.
6. Menghitung total pembayaran secara otomatis.
7. Menampilkan struk transaksi yang berisi rincian pembayaran.
8. Melakukan transaksi baru tanpa menjalankan ulang program.

## 4. Teknologi yang Digunakan

- Bahasa pemrograman: Java
- IDE: Apache NetBeans
- Input pengguna: Scanner
- Konsep pemrograman: Variabel, tipe data, operator aritmatika, percabangan, perulangan, dan method.

## 5. Cara Menjalankan Program

1. Buka aplikasi Apache NetBeans IDE.
2. Buka proyek GameZoneRental.
3. Buka folder Source Packages.
4. Buka package gamezonerental.
5. Buka file GameZoneRental.java.
6. Jalankan program dengan klik kanan pada file GameZoneRental.java, kemudian pilih Run File.
7. Masukkan nama pelanggan sesuai instruksi yang muncul.
8. Pilih konsol PS4 atau PS5.
9. Masukkan durasi penyewaan dalam jam.
10. Pilih apakah ingin menambahkan minuman.
11. Periksa struk dan total pembayaran yang ditampilkan.
12. Pilih Y untuk melakukan transaksi baru atau T untuk mengakhiri program.

## 6. Contoh Perhitungan

Contoh transaksi penyewaan PS5 selama 4 jam dengan tambahan minuman:

- Biaya sewa: 4 × Rp12.000 = Rp48.000
- Diskon 10%: Rp4.800
- Biaya minuman: Rp5.000
- Total pembayaran: Rp48.000 - Rp4.800 + Rp5.000 = Rp48.200
